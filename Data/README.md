# Data

This directory and its subdirectories contain the data.

- `1_ExperimentDesignInfo`: contains information about the experiment and it's implementation
- `2_TimeSeriesData`: contains the untransformed and transformed (for convenience) time series data of taxa abundances, community biomasses and oxygen. The time series are untransformed (e.g. not interpolated)
- `3_ForecastsResults`: contains the saved (for convenience) forecasts results. This data also already include the calculated time series metrics
