# BiodiversityLightAndEcoForecasts
This is the repository to the article "Biodiversity increases the forecastability of species abundances in changing environments".


[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15106928.svg)](https://doi.org/10.5281/zenodo.15106928)


The two main directories are the following (more information is given within them):

- `Data`: contains the complete data to reproduce all the data processing, statistical data analyses, forecasts, figures and tables. It includes all the experimental information, both untransformed and transformed (i.e. processed) time series, and for convenience also all forecast results.
- `r`: contains the complete code necessary to reproduce all the data processing, statistical data analyses, forecasts, figures and tables.
