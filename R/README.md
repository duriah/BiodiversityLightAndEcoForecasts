# Data

This directory and its subdirectories contain the code. All subdirectories can be used independently without having to run the other subdirectories (the necessary data for each step is stored in the repository).

- `1_Functions`: almost all functions written by the authors are stored here
- `2_TimeSeriesProcessing`: the time series are processed here starting from the untransformed time series.
- `3_Forecasting_and_TimeSeriesMetrics`: the time series are forecasted here and the time series metrics are calculated
- `4_StatisticalDataAnalysis`: the complete statistical data analysis after the forecasts and time series metrics calculation is done in here. All tables and figures of the supplement are reproduced. In the case of the main text figures, they are not shown in the pdf output but they are computed in the code (they are then shown in `5_MainFiguresAndTables`).
- `5_MainFiguresAndTables`: contains the code and the output for each of the main text figures and the main text table.
